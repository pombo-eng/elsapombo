# elsapombo.com

Sitio estático de Elsa Pombo — Casas, tierra y vida en el campo.

- `index.html` — página principal (React 18 + Babel por CDN)
- `app.jsx`, `tweaks-panel.jsx` — componentes
- `assets/` — imágenes
- `CNAME` — dominio personalizado para GitHub Pages

Publicación: GitHub Pages desde la rama `main`, carpeta raíz.
